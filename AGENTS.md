## UI rules
- Улучшай интерфейс без смены основной функциональности.
- Сохраняй текущую структуру страницы, если нет явной причины менять её.
- Делай дизайн визуально целостным: единая типографика, одинаковые радиусы, тени, отступы, состояния hover/focus/disabled.
- Не используй случайные inline-стили, если можно вынести в общие классы или CSS-переменные.
- Предпочитай design tokens через CSS custom properties.
- Соблюдай адаптивность: mobile-first, корректное поведение от 320px.
- Учитывай accessibility: достаточный контраст, видимый focus, aria-атрибуты там, где нужно.
- Не добавляй тяжёлые UI-библиотеки без необходимости.
- Перед завершением работы проверь визуальную консистентность всех кнопок, полей, карточек, модалок и таблиц.
